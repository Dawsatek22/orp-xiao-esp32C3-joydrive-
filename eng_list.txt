Summary and warnings:
The tutorial video instructions is explained in subtitles so be aware of that,This project uses 3 to 9v power so be careful,The cad parts used here in this project come from https://openroboticplatform.com/,Some stl file names are changed to make it easier to recognise,
The links for materials and tools are more for reference and not necessary the place to aquire them,
Be careful with the wiring so that it not can cause damage to the board or the breadbord power supply,
If there is any mistakes please comment back in the videos comment section so that i can fix it.
Recommended skills:
Programming arduino/esp32 boards in the arduino ide,Soldering,Using the Bluepad32 library,Working with 3 to 9v power,
3d printing or aquiring of nessacary cad parts.


Recommended software:
Arduino ide https://www.arduino.cc/en/software#ide,Bluepad32 library https://bluepad32.readthedocs.io/en/latest/,esp32 board library.
